[Barber予約管理アプリ(プロトタイプ)](https://github.com/rabin0630/barber151)

理容室で使用する予約管理ツール(https://junrabin.com)
- **概要**: 行きつけの理容室が電話予約だったため、ネットで簡単に予約するために予約管理アプリを作成。営業して商談までいき、ここでさらに**ITは人の働き方を変える可能性がある**ことを知った思い入れのあるリポジトリです。
- **技術**: HTML/CSS/Java Script/Type Script/Python/AWS/Docker
- **工夫したこと**:
  - 電話予約に慣れたお客さんでも迷わないよう、予約を「①メニュー選択 → ②日時指定 → ③登録情報の入力」の3ステップに分割。1画面で考えることを1つに絞り、次に何をすればいいかをアプリ側が案内する**システム主導型（ウィザード形式）**の画面遷移を採用しました。
  - 順番にも意図があり、メニューを先に選ぶことで所要時間が決まり、ステップ2ではその時間で予約可能な枠だけを表示できます。これにより「選んだのに入れない」という手戻りを防いでいます。
