### 🎮 Main Projects
📋 **TMD CHECKER**（副業先から掲載許可済み） 🍄参画期間：6ヶ月

カメラで患者さんの口の開け閉めを撮影し、顎の動きがまっすぐかどうかをAIで解析する、歯科医院向けのデスクトップアプリ（Windows / macOS）

- **概要**：
  歯科医師が使うデスクトップアプリ。患者さんがカメラに向かって口を開け閉めすると、AIが顎の動きの歪みをチェックします。録画データは患者ごと・診察日ごとに、カルテのように保存されます。
- **技術**：React / TypeScript / Python / pywebview / MediaPipe / PyAV / Pillow / pytest
- **貢献したこと**：
  - **新機能の実装**：
    社長から口頭で受けた要件をもとに、詳細設計書の下書きを GitHub の Issue に書き、承認を得てから AI も活用して実装しました。PR を出し、レビューを経て develop ブランチにマージされました。主に次の機能を担当しました。
    - **録画の破棄機能**：録画を削除する機能を実装しました。バックエンドの API からフロントエンドの画面、自動テストまで一人で実装しました。
    - **患者IDの自動生成**：患者を新規登録するときの患者ID自動生成機能を実装しました。
    - **確認モーダル**：録画中や設定中に画面を移ろうとしたとき、中断するか確認するモーダルを追加しました
    - **新規患者登録画面** : 新規患者を登録するためのモーダルを新規作成しました。フロントエンドで入力してからバックエンドを経由し、データベースに保存されるまで、またテストコードの実装の一通り行いました。
  
  - **デバッグ**：
    テストで見つけた不具合について、原因がフロントエンドとバックエンドのどちらにあるかを調べ、修正まで担当しました。（例：撮影日時がいつも9時と表示されたり、解像度を「1980x1080」と選択したにも関わらず他の解像度が選択される不具合の調整」
  - **テスト**：
    画面の表示項目とボタンを洗い出し、操作したときの動きを1つずつ手動で確かめました。あわせて、実際に操作しながら気になる挙動を探す探索的テストも行いました。また、pytest で自動テストを書き、修正したところが再び壊れないようにしました。
  - **ドキュメント整備**：
    主要な関数に docstring や JSDoc を追加・修正し、コードを読みやすくしました。

💻[Discord 勤怠管理bot](https://github.com/rabin0630/DiscordWorkLogger)(個人開発)

Discordを用いた勤怠管理Bot。
- **概要**: 副業先で打刻を打つとき、社長に挨拶すると同時に打刻を打ってくれるBotをDiscordで作成しました。
- **技術**: Python/Docker
- **工夫したこと**:
  - **技術**: Python / discord.py / FastAPI / MySQL / SQLAlchemy / Docker
- **工夫したこと**:
  - **アーキテクチャを明確にした**：Bot（画面）・API（処理）・DB（保存）の3層構造に分ける設計にしました。どこを直せばいいかが明確になり、機能追加や修正がしやすくなっています。
  - **要件定義から順番に進める**：要件定義・基本設計を書き、フローチャートやシーケンス図で処理の流れを詳細設計書で書きつつ実装に入りました。
  - **型アノテーションで静的型付け言語のように書く**：Pythonは動的型付け言語のため、型を書かなくても動きます。しかしそのままだと、関数に何を渡して何が返ってくるのかがコードから読み取れず、型の間違いも実行するまで気づけません。そこで関数の引数・戻り値に型アノテーションを付け、静的型付け言語のように書くことを意識しました。エディタの補完や警告が効くようになり、ミスを書いている段階で見つけられます。また、APIの入出力はPydanticで型を定義し、想定外のデータが来たときは処理に入る前に弾くようにしています。
  - **本番と開発の環境を分ける**：開発用のBotではコマンド名に `_test` が付くようにし、本番のBotと同じサーバーに入れても衝突しないようにしました。

理容室で使用する予約管理ツール(https://junrabin.com)
- **概要**: 行きつけの理容室が電話予約だったため、ネットで簡単に予約するために予約管理アプリを作成。営業して商談までいき、ここでさらに**ITは人の働き方を変える可能性がある**ことを知った思い入れのあるリポジトリです。

  - 「お客さんと店長は年配の方々」を考慮して作成しました。シンプルを追求し認証を減らしたアプリケーションになりました。
  - 技術の証明のためにDockerでコンテナ化しAWSにデプロイしました。しかし、実際に運用する場合は費用面を考慮してレンタルサーバーを選択します。
